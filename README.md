# Hotel-Management-Enterprise-Network
Enterprise Network Design using Cisco Packet Tracer
Hotel Management Enterprise Network Design using Cisco Packet Tracer

• Designed and implemented a scalable Hotel Management Enterprise Network connecting 3 floors, 10 VLANs, 3 routers, multiple switches, wireless access points, printers, and 30+ end devices to ensure secure and reliable communication.

• Configured 10 VLANs, IEEE 802.1Q trunking, and Inter-VLAN Routing (Router-on-a-Stick) to provide secure departmental segmentation and seamless communication across the network.

• Implemented RIP dynamic routing over WAN serial links between routers, enabling end-to-end connectivity across all floors and remote network segments.

• Designed and configured an optimized IPv4 addressing and subnetting scheme for all VLANs, improving network scalability, efficient IP utilization, and simplified management.

• Integrated wireless access points and shared network printers to provide centralized resource access and enhance operational efficiency across hotel departments.

• Performed 20+ connectivity and troubleshooting tests using Ping, Traceroute, ICMP, and Cisco IOS commands to validate VLAN communication, routing, trunk links, and overall network performance.
